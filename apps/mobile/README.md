## After cloning (normal setup)

You do **not** need to manually add anything to `dependencies`.
All required packages are already in `pubspec.yaml`.

From `apps/mobile`, run:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

If you want to refresh dependencies later:

```bash
flutter pub upgrade
```
